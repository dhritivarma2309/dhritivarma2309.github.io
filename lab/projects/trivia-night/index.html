The idea

Many of my friends and family live far away. I wanted to start hosting trivia nights that bring everyone together, let us compete a little and, most importantly, share a laugh or two.

The product

A Jeopardy-style trivia game for video calls, with a buzzer in every hand.

It has three core capabilities across two personas: the Quizmaster and the Participants.

GitHub Pages

My website's files (HTML, CSS, JS, images) live in my GitHub repo. GitHub Pages publishes them as a public website, and when anyone opens a page, their browser downloads the files from GitHub's servers.

Quizmaster Browser

The Build and Host pages run in the Quizmaster's browser, usually on a laptop. It's where boards are created, by hand or with Claude, and where the game rules run: opening questions, judging answers and updating scores, with every change sent to Firebase for all players to see.

Cloudflare Worker

A small server I set up on Cloudflare, between the Quizmaster Browser and Claude. When the Quizmaster drafts questions with AI, the browser sends the request to the Cloudflare Worker, which checks they're signed in with an allowed Google account, adds the Claude API key and calls Claude. This way, the key never reaches the browser.

Firebase

Google's backend service that the Quizmaster's and participants' browsers connect to. It signs in the Quizmaster with Google, saves their trivia boards, and holds each live game (teams, questions, buzzes and scores), syncing every change to all browsers in real time.

Participant Browser

The Join a Game page runs in each participant's browser, usually on a phone. Participants enter the room code, create or join a team, and buzz in when a question opens. Each change is sent by the browser to Firebase for all participants and the Quizmaster to see.

Claude

AI model that can help draft the trivia questions. The Quizmaster types a theme for a category, and Claude returns five questions from easy to hard. Any question that Claude isn't sure about comes back with a flag, so the Quizmaster can verify it before the game.

My learnings

Tools

Firebase
A real-time database that syncs the board, buzzes and scores across every phone, plus Google sign-in for my board library.
Cloudflare
A small server that keeps the Claude API key out of the browser and lets only me use AI drafting.
Claude
My engineering partner for writing the code and tests, and the model that drafts the trivia questions.
